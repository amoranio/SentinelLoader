Azure connection

Sentinel stores custom logs in a Log Analytics workspace. You can preview parsing without Azure. Sending data needs a workspace and an identity that can ingest (and, if you want the app to create the table, manage tables and DCRs).

Do you need to create a table first?

Yes — the Logs Ingestion API will not accept rows for a table that does not exist. SentinelLoader can create that table for you (a custom _CL table plus a Direct Data Collection Rule). If you would rather create it in the portal, use “existing table” on the last step.

To create the table (optional)

  • Log Analytics Contributor on the workspace
  • Monitoring Contributor on the resource group (creates the DCR)
  • User Access Administrator on the DCR/RG (grants Monitoring Metrics Publisher to this identity)

To ingest only

  • Table and Direct DCR already exist
  • Monitoring Metrics Publisher on that DCR
  • You will paste the DCR immutable ID, stream name, and ingestion endpoint

Bulk upload

Drop CSV, TSV, JSON, or JSONL files. Encoding and delimiter are detected; you can override after parse if a file looks wrong.
